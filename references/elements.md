# 公文各要素

按 GB/T 9704—2012，公文格式分为版头、主体、版记三部分，要素自上而下排列。

## 一、版头

| 要素 | 位置与格式 | 本技能对应命令 |
|---|---|---|
| 份号 | 左上角第一行，6 位阿拉伯数字 | — |
| 密级和保密期限 | 左上角第二行 | — |
| 紧急程度 | 左上角第三行 | — |
| 发文机关标志 | 红色小标宋，居中；可只写机关名，也可写"机关名＋文件" | `\gworg{}` / `org()` |
| 发文字号 | 机关代字＋年份＋序号，如「教字〔2026〕15 号」，三号仿宋，居中 | `\gwdocno{}` / `docno()` |
| 签发人 | 上行文才需要，与发文字号同一行，居右 | — |
| 红色分隔线 | 发文字号下方，与版心同宽 | 由 `\gwdocno` 自动生成 |

年份用六角括号「〔〕」，不是方括号「[]」，也不是圆括号「（）」。

## 二、主体

| 要素 | 格式 | 本技能对应命令 |
|---|---|---|
| 文件标题 | 二号小标宋，居中，回行时词意完整 | `\gwtitle{}` / `title()` |
| 主送机关 | 三号仿宋，顶格，末尾加全角冒号 | `\gwto{}` / `to()` |
| 正文 | 三号仿宋，首行缩进 2 字 | `\gwbody{}` / `body()` |
| 一级标题 | 三号黑体，形如「一、」 | `\gwhone{}` / `h1()` |
| 二级标题 | 三号楷体，形如「（一）」 | `\gwhtwo{}` / `h2()` |
| 三级标题 | 三号仿宋加粗，形如「1.」 | `\gwhthree{}` / `h3()` |
| 附件说明 | 正文之后空一行，左空 2 字，多个附件用阿拉伯数字编号 | `\gwattach{}`／`gwattachcont{}` / `attach()` |
| 发文机关署名 | 右空 2 字 | `\gwsign` 第一个参数 |
| 成文日期 | 右空 4 字，用阿拉伯数字标全年月日 | `\gwsign` 第二个参数 / `sign()` |
| 印章 | 骑车压月、上大下小，压成文日期 | 需图片叠加，本技能不含 |
| 附注 | 成文日期下一行，左空 2 字，加圆括号 | — |

层次序数只用三级：`一、`→`（一）`→`1.`。第四层用 `（1）`，但正式公文一般不用到第四层。

## 三、版记

| 要素 | 格式 |
|---|---|
| 抄送机关 | 版记第一条分隔线之下，三号仿宋，左空 1 字 |
| 印发机关和印发日期 | 版记最后一条分隔线之上，三号仿宋 |
| 页码 | 4 号宋体，数字两侧各一条一字线；单页居右、双页居左 |

## 四、顺序速查

```
版头
  份号 / 密级 / 紧急程度
  发文机关标志
  发文字号（＋签发人）
  红色分隔线
主体
  标题
  主送机关
  正文（含各级标题）
  附件说明
  发文机关署名
  成文日期
  印章
  附注
  附件
版记
  抄送机关
  印发机关和印发日期
```

## 五、文种与标题写法

标题一般写作「发文机关＋事由＋文种」，例如：

- `××大学关于开展课程建设的通知`
- `××学院关于报送年度总结的报告`
- `××办公室关于××事项的请示`
- `××委员会关于同意××的批复`
- `××部关于××工作的函`

通知用于发布、传达要求下级机关执行和有关单位周知的事项；报告用于向上级汇报工作、
反映情况；请示用于向上级请求指示或批准，**一文一事**；函用于不相隶属机关之间商洽工作。

## 六、日期写法

成文日期用阿拉伯数字，年月日标全，不编虚位：

- 正确：`2026年10月26日`
- 错误：`2026年10月26号`、`二〇二六年十月二十六日`（后者是习惯写法，正式公文用阿拉伯数字）

注：手写样例中为便于排版常写作汉字数字，正式印发应以阿拉伯数字为准。

## 七、常见要素的省略

不是每份公文都要全部要素：

- 内部通知可以不要份号、密级、抄送
- 便函可以不要红色分隔线与版记
- 但**标题、主送机关、正文、成文日期**四件不能省
